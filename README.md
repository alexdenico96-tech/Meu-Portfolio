# Meu Portfólio

Portfólio pessoal construído do zero com HTML, CSS e JavaScript puro (sem frameworks),
como projeto de aprendizado de front-end, passo a passo.

🔗 **Site publicado:** https://SEU_USUARIO.github.io/portfolio/

## 🚧 Status
Concluído — estrutura base pronta para receber conteúdo real (textos, projetos, links).

## 🛠️ Tecnologias
- HTML5 (tags semânticas)
- CSS3 (Flexbox, Grid, Media Queries, variáveis CSS)
- JavaScript Vanilla (DOM, Intersection Observer, validação de formulário)

## ✨ Funcionalidades
- Layout responsivo (desktop, tablet e mobile)
- Menu de navegação com botão hambúrguer no mobile
- Rolagem suave entre seções
- Seção de estatísticas com contador animado ao entrar na tela
- Formulário de contato com validação em JavaScript
